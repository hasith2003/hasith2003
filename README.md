## 🏆 Featured Projects

### 🫀 [Real-Time Multimodal Cardiac Detection System](https://github.com/hasith2003)
*Awarded All Island 2nd Place at IEEE CAS SDC 2026*
- **The Tech:** Implemented on-chip **BANLMS adaptive filtering** on STM32 for noise cancellation.
- **The AI:** Architected a **J-CRNN with Bi-LSTM** in PyTorch for ECG/PCG classification (93%+ Accuracy).
- **Impact:** Real-time heart disease screening on a portable embedded device.

### 👶 [Hushaby: Smart IoT Baby Cradle](https://github.com/hasith2003)
- **The Tech:** Developed a cloud-based system using **ESP32** and **Google Cloud Run** with a custom I2S audio sampling pipeline.
- **The AI:** Engineered an **XGBoost + SVM ensemble model** (94.5% accuracy) for real-time cry detection and automated response.
- **Connectivity:** Integrated Firebase and MQTT for seamless environmental monitoring and data sync.

### 🦾 [Distributed Bionic Arm Control System](https://github.com/hasith2003)
- **The Tech:** A distributed architecture utilizing a pocket-mounted **Raspberry Pi 5** for heavy processing and a wrist-integrated **ESP32-S3** for motor control.
- **Focus:** Designed specifically for transradial amputees with 5-10cm of residual forearm.
